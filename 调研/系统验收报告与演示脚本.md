## 三、甲方演示脚本（建议 12 分钟）

| 步骤 | 操作 | 预期与讲解点 |
|---|---|---|
| 1 | 打开系统首页 | 介绍产品定位、三个角色入口（管理员 / 会员 / 教练） |
| 2 | 进入登录页，用 admin 登录 | 展示工作台：会员 2、有效卡 2、今日课程 2、本月营收 |
| 3 | 会员管理 → 新增会员 | 演示手机号唯一校验；新增后列表即时刷新 |
| 4 | 会员卡管理 → 为会员开年卡 → 续费 | 演示重复开卡拦截、续费顺延到期日、缴费流水 |
| 5 | 教练管理 → 尝试停用阮腾 | 提示"名下还有未结束课程"——业务规则防护 |
| 6 | 排课管理 → 新增一节明天的课 | 演示教练/教室时段冲突校验；保存后出现在列表 |
| 7 | 切到会员端（启动台开新窗口）→ 课程预约 | 预约成功显示位置号；满员课程可排候补 |
| 8 | 会员端取消预约 | 按"距开课时间"分档：>6h 免责、2–6h 计临时取消、<2h 不可取消 |
| 9 | 切到教练端 → 预约名单 → 签到 | 仅当天课程可签到；签到后写入到店记录 |
| 10 | 管理端 → 会员预警 | 到期预警（7 天内）与流失预警（14 天未到店），可回填处理结果 |
| 11 | 管理端 → 到店记录 | 区分团课签到与自助训练，说明到店率口径 |
| 12 | 教练端 → 本月课时结算单 | 按节汇总课时费，可导出（后续版本） |

演示建议：全程用多角色启动台开三个窗口，避免反复登录；每步只讲"解决了什么问题"，不逐字段解释。

## 四、商用部署要点

1. **切换 MySQL**：使用 `--spring.profiles.active=mysql`，先执行 `db/schema.sql` 建表，再执行 `db/data-mysql.sql` 初始化演示数据（日期同样基于当天推算）。
2. **改口令**：交付前必须修改 `admin` 默认口令，并把 `sys_user` 中演示账号改为客户实际账号。
3. **关闭演示开关**：生产环境建议将 `spring.sql.init.mode` 设为 `never`，避免重启重置数据；H2 控制台保持关闭。
4. **会话**：当前令牌存于进程内存（`TokenStore`），单实例可用；若做多实例部署需换 Redis 或 JWT。
5. **备份**：MySQL 环境需配置每日备份（`mysqldump`），H2 仅用于演示。
